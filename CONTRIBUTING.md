# Contributing to Arix

The project is currently in its early stage, so your contribution could be of great help.

## Pull Requests

Try to keep PRs small and atomic. <br>
For bug fixes, please include a test that reproduces the issue when possible. <br>
For performance improvements, please include benchmark results when possible. <br>

## Issues

When reporting a bug, please include:
- a minimal reproduction
- expected behavior
- actual behavior

## About AI

AI contributions are not allowed.
