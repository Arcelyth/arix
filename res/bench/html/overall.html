Building a streaming parser

7 September 2026

A streaming parser consumes input incrementally while preserving the state required by tokenization and tree construction. It must handle boundaries inside tags, comments, character references, and text.

Correctness comes first; measurement shows where optimization matters.

  • Decode the input stream.
  • Emit tokens without unnecessary copies.
  • Construct nodes using the active insertion mode.
  • Preserve namespaces and source order.
